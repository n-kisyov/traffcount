Appearance & Window Behavior

Customize how TraffCount looks and behaves on your Windows 11 desktop.

Color Theme
Switch between Dark, Antigravity IDE (Dark Modern), Nord, Dracula, Emerald, and Light themes.
Stay on Top (Always on Top)
Keep the TraffCount window pinned above other desktop windows.
Start on System Boot
Launch TraffCount minimized to the system tray automatically when Windows starts.
Start Minimized to System Tray
When starting TraffCount manually, start in the system tray without opening the window.
Bandwidth Speed Units
Display real-time throughput in bits/sec (Mbps) or bytes/sec (MB/s).
Hide Software Loopback Adapters
Filter out virtual loopback interfaces from live views.
UI & Graph Update Cadence
Controls dashboard redraw and live socket table polling frequency.
Show Sparkline in Mini-Widget
Include the 60-second throughput graph beneath speeds in Mini-Widget mode.

Windows Background Service

Run TraffCount's collector as an automatic Windows Service (`TraffCountService`) so traffic is counted 24/7 even before login.

Data Cap & Bandwidth Alerts

Configure a monthly billing-cycle data cap and sustained bandwidth spike alerts with Windows 11 system tray notifications.

Enable Monthly Data Cap
Show billing-cycle quota progress bar and notify at 80% and 100% usage.
Monthly Data Cap Limit (GB)
Combined Inbound + Outbound quota per billing cycle.
Billing Cycle Reset Day (1–28)
Day of each month when the quota counter resets.
Sustained Spike Alert Threshold (Mbps)
Trigger a system tray alert when throughput exceeds this rate (0 = disabled).
New Application Network Access Alert
Show a Windows 11 tray notification when a new .exe accesses the network for the first time.

Connectivity & Ping Monitors

Configure real-time ICMP/TCP latency & packet-loss probes shown on the dashboard.

Auto-Probe Default Gateway (ICMP)
Continuously ping your router / gateway IP to separate LAN/Wi-Fi jitter from ISP latency.
Custom Monitor Targets
Add any IP, hostname (ICMP), or host:port (TCP) target alongside 1.1.1.1 and 8.8.8.8.

Database & Maintenance

Configure historical retention, download an atomic SQLite snapshot, or clear traffic counters.

History Retention Period
Automatically prune hourly and per-app counters older than the selected window.
Database is automatically checkpointed on backup and pruned on startup according to your retention period.
